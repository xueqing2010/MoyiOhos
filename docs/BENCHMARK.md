# 质量与性能基准（P1-10）

## 目标

用固定测试集衡量 OCR、翻译、排版和性能，避免“凭感觉优化”。

## 测试集

建议 30–50 页，覆盖：

- 日文黑白漫画：气泡对话、竖排、拟声词、跨页；
- 彩色页：深色背景、渐变、手写体；
- 低清页：短边 < 800px；
- 英文/韩文混排；
- 双页跨页。

素材必须可合法使用（自建/授权/开放许可），不提交受版权保护的漫画原图。

## 指标

| 指标 | 说明 | 目标 |
|---|---|---|
| OCR CER | 字符错误率 | 越低越好；当前未建立基线 |
| 翻译质量 | COMET / BLEU / chrF++（有参考译文时） | 相对基线提升 |
| 人工评分 | 1–5 分：可读性、语气、专名一致 | ≥4 为目标 |
| 文本溢出率 | 超出气泡/框的比例 | <5% |
| 原文残留率 | 去字后仍可见原文的比例 | <10% |
| p50/p95 延迟 | 单页 OCR + 翻译 + 去字 | 平板 p50 <5s |
| 峰值内存 | 单页 | <1.8GB |
| 发热/降频 | 连续 50 页后 p95 | 不高于初始 1.5× |

## 执行方式

1. 固定设备、系统版本、HAP 版本；
2. 清空翻译缓存后逐页翻译；
3. 从 hilog 抓取：

```text
PageTranslateService: page <id> timings: ocr=...ms, translate=...ms, total=...ms
LocalOcrEngine: local OCR lines=...
PageImageCleaner: cleaned page ...
```

4. 记录每页结果，计算 p50/p95；
5. 截图保存原文/译文/去字底图；
6. 与上一版本对比，只有指标提升才合并。

## 验收门槛

- OCR/翻译质量不低于上一版；
- 平板 p50 <5s，手机 <7s；
- 文本溢出率 <5%；
- 无整页白块/大框误覆盖；
- 连续 50 页无明显降频或崩溃。
