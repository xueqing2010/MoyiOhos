# 提交材料清单与流程

## 一、提交前必须完成的核对

- [ ] 申请人全称、证件号码、地址、电话、邮箱准确。
- [ ] 软件全称、版本号在申请表、说明书封面、源程序页眉三处一致。
- [ ] 开发完成日期早于申请日；未发表则不填首次发表日期。
- [ ] 源程序为申请人原创部分；第三方代码/生成代码已剔除或说明。
- [ ] 源程序前后各 30 页、每页 50 行；本包已生成 60 页 PDF。
- [ ] 说明书页眉、页码、截图清晰；本包已生成 15 页 PDF。
- [ ] 文档中不包含 API Key、密码、内网地址、个人信息。
- [ ] 申请人签字/盖章的独立开发与权属声明。
- [ ] 个人身份证/公司营业执照扫描件。
- [ ] 如职务/委托/合作开发，附权属证明。
- [ ] 软件名称已做商标/应用名称检索（至少检索第 9、42 类）。

## 二、在线申请流程

1. 进入中国版权保护中心软件著作权登记系统，注册/登录。
2. 在线填写申请表，保存申请号。
3. 打印申请确认签章页，签字/盖章后扫描上传。
4. 上传：
   - 源程序鉴别材料 PDF（本包 02 文件导出）；
   - 文档鉴别材料 PDF（本包 01 文件导出）；
   - 身份证明；
   - 权属证明/声明（如适用）。
5. 提交后等待受理；如收到补正通知，按补正意见修改后重新上传。
6. 取得证书后核对：软件名称、版本、著作权人、登记号、日期。

> 具体系统字段、格式、受理时限以中国版权保护中心当期要求为准；本包不承诺审批结果。

## 三、PDF 材料

本包已生成并核对：

- 02-源程序鉴别材料.pdf：60 页，每页 50 行；
- 01-软件说明书.pdf：15 页。

如果修改了 DOCX，请重新用 Word/Pages 导出 PDF，并检查：

1. 源程序正好 60 页；
2. 每页 50 行；
3. 页眉左侧软件名称/版本，右侧页码；
4. 中文无乱码、表格/截图无截断。

## 四、费用与证书

- 官方软著登记费、证书费：0 元（2017 年 4 月 1 日起停征）。
- 电子证书：用户中心下载 PDF，带电子签章，可验签。
- 纸质证书：不是默认必发；如需，按中心补发/换发/增发指引咨询，详见 10-证书形式与费用说明.md。
- 代理服务费、快递费、打印费等按实际发生，不属于官方收费。
