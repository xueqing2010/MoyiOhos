## 重要提醒

- 本包是**申请准备材料**，不是登记机构出具的受理/证书。
- 源程序样本只用于登记鉴别，不能替代真实源代码仓库。
- 第三方组件与模型不纳入原创范围；申请前请核对许可。
- 申请人必须对“独立开发、权属清晰、无侵权”声明负责，签字前请逐项核实。
- DOCX 需在 Word/Pages 中导出 PDF；导出后核对页数、页眉和字体未错位。
